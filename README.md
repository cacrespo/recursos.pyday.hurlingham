# Recursos Oficiales — PyDay Hurlingham 🐍

Repositorio de almacenamiento de activos estáticos, hojas de estilo (`custom.css`), plantillas (`index.html`), logotipos oficiales y documentos de soporte para las ediciones del **PyDay Hurlingham** alojado en [EventoL](https://eventos.python.org.ar/events/pyday-hurlingham-2026/).
